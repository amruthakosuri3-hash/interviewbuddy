InterviewBuddy AI is a Streamlit-based AI interview preparation web application that helps students prepare for technical and HR interviews.

Key Features
🔐 User registration and secure login
💼 Job-role based preparation
📝 Interactive quizzes with difficulty levels
🤖 AI Interview Chat using Ollama + Llama 3.2 3B
📊 Quiz scores and progress tracking
💾 SQLite database for users and quiz attempts
🔒 Password protection using PBKDF2-HMAC-SHA256

Technology Stack: Python, Streamlit, SQLite, Ollama, Llama 3.2 3B, Requests.

Main Goal: To provide students with a single platform to learn, practice quizzes, interact with an AI interview coach, and track their interview preparation progress
